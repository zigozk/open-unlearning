# Legacy PIPER Work

本目录集中归档 BRIDGE 之前的 PIPER / FABLE-PI 相关工作。

## Contents

- `experiments/piper/`：PI predictive validity probe、PIPER local KL intervention 和结果汇总脚本。
- `sbatch/piper/`：旧 PIPER 探针、intervention、official TOFU eval 和 summary 的集群脚本。
- `results/`：旧 PIPER 轻量结果报告以及本地 ignored 的原始结果目录。
- `GPT/`：旧 PIPER / FABLE-PI / 早期 BRIDGE 草稿和方案材料。

## Policy

这些材料只作为历史参考和复现线索保留。新的 BRIDGE 论文线应从 `docs/bridge/`、`experiments/bridge/` 和 `sbatch/bridge/` 继续推进。

不要把新的 BRIDGE 代码、实验脚本或结果继续写入本目录。
