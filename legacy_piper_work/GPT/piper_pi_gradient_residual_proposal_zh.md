# PIPER 修改方案：从梯度相似度的一阶近似到有限步预测干扰

## 1. 修改动机

当前 PIPER 的基本形式是：

```text
计算预测干扰分数
选择最容易受损的保留样本
对这些样本加入局部保持约束
```

这个思路可以作为机制实验成立，但如果以顶会标准审稿，它仍然容易被认为是一种样本选择技巧。更强的修改方向不是避开梯度相似度方法，而是正面说明：

```text
梯度相似度只是预测干扰的一阶近似。
PIPER 估计的是一次真实遗忘更新后造成的有限步保留损伤。
预测干扰中不能被梯度相似度解释的部分，可能包含非线性和优化器相关的易损信息。
```

这样，PIPER 就不再只是另一个打分规则，而是对现有梯度冲突分析的扩展。

## 2. 核心理论重述

设遗忘目标为：

```latex
L_f(\theta)
```

某个保留样本的损失为：

```latex
L_r(x_r; \theta)
```

一次虚拟遗忘更新为：

```latex
\theta' = \theta - \eta \nabla_\theta L_f(\theta)
```

PIPER 的预测干扰分数定义为：

```latex
\mathrm{PI}(x_r)
=
L_r(x_r; \theta') - L_r(x_r; \theta)
```

对保留损失做一阶展开：

```latex
L_r(x_r; \theta - \eta \nabla_\theta L_f)
\approx
L_r(x_r; \theta)
-
\eta
\left\langle
\nabla_\theta L_r(x_r; \theta),
\nabla_\theta L_f(\theta)
\right\rangle
```

因此：

```latex
\mathrm{PI}(x_r)
\approx
-
\eta
\left\langle
\nabla_\theta L_r(x_r; \theta),
\nabla_\theta L_f(\theta)
\right\rangle
```

这说明梯度相似度不是和 PIPER 无关的对照，而是 PIPER 的一阶近似。可以定义一阶梯度干扰分数：

```latex
\mathrm{GI}(x_r)
=
-
\eta
\left\langle
\nabla_\theta L_r(x_r; \theta),
\nabla_\theta L_f(\theta)
\right\rangle
```

进一步定义预测干扰残差：

```latex
\mathrm{RPI}(x_r)
=
\mathrm{PI}(x_r) - \mathrm{GI}(x_r)
```

这个残差表示：一次有限步更新造成的保留损伤中，不能被一阶梯度关系解释的部分。

## 3. 修改后的方法变体

### 3.1 梯度相似度局部保持

这是必须加入的强对照。否则审稿人会认为 PIPER 只是更昂贵的梯度相似度。

对每个保留样本计算：

```latex
s_{\mathrm{GI}}(x_r)
=
-
\left\langle
\nabla_\theta L_r(x_r),
\nabla_\theta L_f
\right\rangle
```

选择分数最高的保留样本，加入相同的局部保持约束：

```latex
L
=
L_{\mathrm{unlearn}}

\lambda
\mathbb{E}_{x_r \in V_{\mathrm{GI}}}
\left[
\mathrm{KL}
\left(
p_{\theta_0}(\cdot|x_r)
\Vert
p_{\theta}(\cdot|x_r)
\right)
\right]
```

这个对照用于回答：

```text
PIPER 是否真的比一阶梯度冲突更有信息量？
```

### 3.2 预测干扰局部保持

这是当前 PIPER 的基本版本：

```latex
V_{\mathrm{PI}}
=
\mathrm{TopK}_{x_r}
\left(
\mathrm{PI}(x_r)
\right)
```

目标函数为：

```latex
L
=
L_{\mathrm{unlearn}}

\lambda
\mathbb{E}_{x_r \in V_{\mathrm{PI}}}
\left[
\mathrm{KL}
\left(
p_{\theta_0}(\cdot|x_r)
\Vert
p_{\theta}(\cdot|x_r)
\right)
\right]
```

### 3.3 残差预测干扰局部保持

这是最值得作为新贡献的扩展版本。

```latex
V_{\mathrm{RPI}}
=
\mathrm{TopK}_{x_r}
\left(
\mathrm{RPI}(x_r)
\right)
```

它选择的不是普通的梯度冲突样本，而是：

```text
一阶梯度相似度解释不了，但有限步更新后确实容易受损的保留样本。
```

如果这个方法优于梯度相似度局部保持，那么 PIPER 的独立价值会明显增强。

### 3.4 预测干扰与梯度相似度混合分数

可以定义一个混合分数：

```latex
s_{\mathrm{mix}}(x_r)
=
\alpha \cdot \mathrm{Norm}(\mathrm{PI}(x_r))

(1-\alpha) \cdot \mathrm{Norm}(\mathrm{GI}(x_r))
```

测试：

```latex
\alpha \in \{0.25, 0.5, 0.75\}
```

这个实验用于判断有限步预测干扰和一阶梯度相似度是否包含互补信息。

### 3.5 预测干扰加权保持预算

当前方法是硬选择：

```text
选择前百分之十样本
所有被选样本使用同一个保持权重
```

这个设计较粗。可以改成连续预算分配：

```latex
\lambda_i
=
\lambda
\cdot
\frac{
\exp(\mathrm{PI}(x_i) / \tau)
}{
\sum_j \exp(\mathrm{PI}(x_j) / \tau)
}
```

目标函数变为：

```latex
L
=
L_{\mathrm{unlearn}}

\sum_i
\lambda_i
\mathrm{KL}
\left(
p_{\theta_0}(\cdot|x_i)
\Vert
p_{\theta}(\cdot|x_i)
\right)
```

这样，PIPER 不只是选择样本，而是分配保留预算。

## 4. 必须补充的实验

### 4.1 主对照组

在相同模型、相同划分、相同随机种子、相同训练步数、相同候选保留样本和相同局部保持预算下，比较：

| 方法 | 目的 |
|---|---|
| 原始遗忘方法 | 不加保持项的基线 |
| 随机局部保持 | 排除只是多加保持项带来的效果 |
| 词频语义邻近局部保持 | 排除只是保护语义相近样本的效果 |
| 梯度相似度局部保持 | 排除一阶梯度冲突已经足够的可能 |
| 预测干扰局部保持 | 当前 PIPER |
| 残差预测干扰局部保持 | 检验有限步信息是否超越梯度相似度 |
| 预测干扰加权保持 | 检验连续预算分配是否优于硬选择 |

最关键的比较不是：

```text
预测干扰方法是否优于随机方法
```

而是：

```text
预测干扰方法是否优于梯度相似度方法
```

### 4.2 评价指标

需要同时报告内部代理指标和官方评测指标。

内部代理指标：

| 指标 | 作用 |
|---|---|
| 全体保留样本损伤 | 衡量整体保留能力 |
| 预测干扰高分样本损伤 | 衡量易损样本是否被保护 |
| 梯度相似度高分样本损伤 | 检查梯度相似度选出的样本是否被保护 |
| 遗忘样本损伤 | 衡量遗忘强度 |
| 遗忘答案概率变化 | 衡量遗忘侧行为变化 |

官方评测指标：

| 指标 | 作用 |
|---|---|
| 遗忘质量 | 官方遗忘能力指标 |
| 真实答案比例 | 检查真实答案是否被压低 |
| 问答概率 | 检查目标答案概率 |
| 问答相似度 | 检查生成答案是否仍接近原答案 |
| 模型效用 | 检查整体可用性 |

### 4.3 匹配遗忘质量后的比较

如果论文要声称改善了遗忘和保留之间的权衡，不能只比较相同保持权重下的结果。必须比较遗忘质量接近时的保留损伤：

```text
在遗忘强度相近的实验点中，哪个方法的保留损伤更低？
```

如果不做这一步，结论只能写成：

```text
预测干扰方法在内部代理指标上降低了局部易损保留样本的损伤，
但尚未严格证明改善了遗忘与保留之间的权衡。
```

## 5. 推荐论文表述

较弱表述：

```text
本文提出预测干扰分数，用于选择需要保护的保留样本。
```

更强表述：

```text
本文指出，梯度相似度可以被视为有限步保留干扰的一阶近似。在此基础上，本文提出预测干扰探针，用于估计真实遗忘更新诱发的保留样本易损性，并进一步利用其相对于梯度相似度的残差信息分配局部保持预算。
```

第二种表述更像方法贡献，而不是经验性样本选择。

## 6. 主要审稿风险与应对

### 风险一：预测干扰只是更昂贵的梯度相似度

应对：

```text
加入梯度相似度局部保持和残差预测干扰局部保持实验。
```

### 风险二：保留效果提升只是因为遗忘变弱

应对：

```text
加入匹配遗忘质量的比较，或至少给出遗忘和保留曲线。
```

### 风险三：语义对照太弱

应对：

```text
明确当前语义对照是词频语义邻近对照。
如资源允许，可补充嵌入相似度对照作为附录。
```

### 风险四：前百分之十选择过于任意

应对：

```text
加入预测干扰加权保持和选择比例敏感性实验。
```

## 7. 下一步实现建议

不要立刻扩大到很大的数据集或更多模型。下一步应先做一个聚焦机制实验：

```text
模型：Llama-2-7B-chat-hf
数据：TOFU forget10 / retain90
遗忘方法：NPO
随机种子：0, 1, 2
保持权重：0.1, 0.2, 0.3, 0.5
方法：
  原始基线
  随机局部保持
  词频语义邻近局部保持
  梯度相似度局部保持
  预测干扰局部保持
  残差预测干扰局部保持
  预测干扰加权保持
```

如果残差预测干扰或预测干扰加权保持不能优于梯度相似度局部保持，那么论文应把 PIPER 收缩为诊断工具，而不是主遗忘方法。
