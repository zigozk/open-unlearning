# Legacy Thesis Work

本目录用于归档原本科毕业设计阶段产生的实验材料、调度脚本、绘图脚本、图表和结果文件。

当前归档内容：

- `figures/`：原论文使用或候选使用的图表输出。
- `figures_new/`：后续润色或替换版本的图表输出。
- `sbatch/`：原毕设实验的集群提交脚本、结果收集脚本和中间检查脚本。
- `test/`：原毕设阶段用于绘图、结果检查或临时分析的脚本与小型输入文件。
- `logs/`：原实验日志。
- `saves/`：原实验结果、汇总表和分析输出。
- `tofu_eval_summary.csv`：原评估汇总文件。
- `毕设最后的补充实验.md`：原毕设补充实验记录。

根目录保留框架主体代码与配置，例如 `src/`、`configs/`、`scripts/`、`docs/`、`assets/`、`community/`。后续新工作如果仍基于同一框架开展，应优先在根目录或新的专用实验目录中组织，避免继续向本归档目录写入新实验产物。
